# React Components Assignment

App.jsx imports and renders Index.jsx. Index.jsx uses the reusable Button, Layout and UserCard components. Layout renders Header, its children, and Footer.

## Run in VS Code

Open the extracted folder containing package.json and execute:

```powershell
npm install
npm run dev
```

Open the URL Vite prints, such as http://localhost:5173/. If another project uses port 5173, use `npm run dev -- --port 5174`.
